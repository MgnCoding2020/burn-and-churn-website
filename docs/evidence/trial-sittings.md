# The trial, sitting by sitting

Written 2026-11-14 for Michael's busy month (work, school, exams). It puts the trial test plan (`trial-test-plan.md`) into short sittings, with the steps that only need **time to pass** started first. Week 4 is a buffer.

- **Step-by-step clicks:** `docs/tenant-setup.md`. **Expected results:** `trial-test-plan.md`.
- **Screenshots:** save them to `burn-and-churn-design\originals` with the names given. Claude files them into `docs/evidence/`, boxes anything personal and writes the notes.
- **Phase 7 code is already built and tested against stand-ins** (ADR-0039, ADR-0045). The trial plugs in real SharePoint and Entra: nothing in the first two weeks waits for new code, except **My shifts**, and only if T-SH-01 keeps the SharePoint Schedule.
