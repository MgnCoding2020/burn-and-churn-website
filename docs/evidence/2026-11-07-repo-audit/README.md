# Repository audit (2026-11-07)

**Why:** Phase 2 went live in production on 2026-11-07. The same day, the privacy and security pages were found still describing sign-in as planned (fixed in PR #28). This audit checks whether anything else in the repository says something the code, tests or evidence don't support. Program control: assessment and continuous monitoring (CA-2, CA-7).

**Method:** every tracked file read against the code, the tests and the dated evidence; git history searched for the tenant and client IDs; the hub's CR-002 compared with what is live. Auditor: Claude Code, at Michael's request; findings reviewed by Michael.

| Check                                         | Result                                                                                                                                                                                       |
