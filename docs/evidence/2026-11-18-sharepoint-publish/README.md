**What it proves:** a manager changes the café's content in SharePoint and publishes it, without touching the website's code or database. Rows that break a rule are reported by name and never published. Staff-only content stays in the portal. Every run is recorded with who started it.

**Found and fixed:** the first Publish showed the latte as "Caff├¿ Latte". The seed script (`setup-sharepoint.ps1 -Seed`) had read the Node helper's UTF-8 output with Windows PowerShell 5.1's console code page (437), so the accent was garbled **in SharePoint**; the website showed what SharePoint held. The script now reads that output as UTF-8 (reproduced under code page 437, then fixed). Daniel re-typed the name in SharePoint. He typed "Café" where the seed has "Caffè"; both are fine for a fictional menu.
